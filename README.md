# Heart-Disease-Dataset
Goal: Data preprocessing and exploratory analysis of Heart Disease dataset.

Dataset: 303 samples, 13 features, target = heart disease (0 = No, 1 = Yes).

Tasks: Cleaned data, handled missing values, encoded features, visualized distributions and correlations.

Tools: Python, Pandas, Matplotlib, Seaborn.

Usage: Run the notebook/script to reproduce analysis.
